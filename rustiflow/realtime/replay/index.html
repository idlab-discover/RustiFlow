Module replay 

Source
Expand description

Synthetic event replay through the realtime userspace pipeline.

Events are generated in memory before timing starts, then drained through the same batching, dispatch, shard and export stages as live capture. No eBPF program is loaded, so the result is the userspace ceiling independent of any traffic generator.
