Module ebpf_objects 

Source
Expand description

Locates the eBPF object files that realtime capture loads at runtime.

A release install keeps the objects beside the executable’s prefix in <prefix>/lib/rustiflow/, while development builds leave them in Cargo’s target directory. Both layouts must work without rebuilding the binary.

Constants§

EBPF_DIR_ENV
Overrides every other location. When set, only this directory is searched, so a typo fails loudly instead of silently loading a different build.

eBPF target the userspace loader expects; the only supported one today.
