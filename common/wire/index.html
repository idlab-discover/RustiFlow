Module wire 

Source
Expand description

Wire layouts of the link, network and transport headers RustiFlow reads.

Every header is Unaligned and accepts any bit pattern, so it can be borrowed from untrusted packet bytes with a single length check, and multi-byte fields carry their network byte order in their type.
